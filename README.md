# Помодоро-таймер

Клиентское веб-приложение для работы по методике Pomodoro: чередование интервалов работы и отдыха с автоматическим переключением этапов, счётчиком помодоро, звуковым сигналом, статистикой и светлой/тёмной темой.

Приложение работает полностью в браузере — без сервера, регистрации и базы данных. Все данные (настройки, тема, история) хранятся в `localStorage`.

## Возможности

- Три типа этапов: **работа** (25 мин), **короткий перерыв** (5 мин), **длинный перерыв** (15 мин).
- Длинный перерыв запускается после каждых 4 завершённых помодоро, иначе — короткий.
- Управление: **Старт / Пауза / Продолжить / Сброс / Пропустить этап**.
- Глобальный хоткей: `Пробел` или `Enter` — старт/пауза (когда фокус не в поле ввода и не на кнопке).
- Точный обратный отсчёт: источник истины — абсолютное время завершения этапа, поэтому при сворачивании вкладки отсчёт не дрейфует.
- Звуковой сигнал по завершении этапа (Web Audio API; браузерные уведомления не используются).
- Настройка длительностей работы и перерывов (1–180 минут) с сохранением в `localStorage`.
- Статистика: помодоро за текущую сессию, за сегодня и всего; история ограничена последними 500 записями.
- Светлая и тёмная темы с переключателем и сохранением выбора.
- Адаптивная вёрстка и базовые требования доступности (семантика, ARIA, управление с клавиатуры).

## Технологии

- **React 18** + **TypeScript**
- **Vite** (сборка и dev-сервер)
- **CSS Modules** для стилизации
- **Vitest** + **React Testing Library** для тестов
- **ESLint** для линтинга

## Требования

- Node.js 18+ и npm

## Установка и запуск

```bash
npm install       # установка зависимостей
npm run dev       # запуск dev-сервера (http://localhost:5173)
```

| Команда              | Описание                                    |

## Схема данных в localStorage

| Ключ                 | Значение                                                      |
| -------------------- | ------------------------------------------------------------- |
| `pomodoro:settings`  | `{ workMin, shortBreakMin, longBreakMin }`                    |
| `pomodoro:theme`     | `'light' \| 'dark'`                                           |
| `pomodoro:history`   | массив `{ completedAt: string (ISO), workMinutes: number }[]` |

Некорректные или повреждённые данные валидируются и заменяются значениями по умолчанию.

## Тестирование

Тесты покрывают чистую логику переходов этапов и форматирования времени, хук таймера, а также ключевые сценарии компонентов и интеграционные сценарии приложения.

```bash
npm run test
```

## Ограничения

Проект реализует MVP согласно `ТЗ.md`. Вне области текущей версии: автостарт следующего этапа, системные браузерные уведомления, расширенная статистика и графики, синхронизация между устройствами и аккаунты.
